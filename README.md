# 家系圖快速製作器 V6.1.0

## 使用方式
- `index.html` 可直接放到 GitHub Pages，也可雙擊離線使用。
- 本機圖形辨識與瀏覽器 TextDetector 可離線執行。
- Tesseract.js 備援需要網路下載 OCR 引擎與繁體中文語言資料，但圖片仍在瀏覽器處理。
- AI 協助判讀需要自行部署 `cloudflare-worker/` 內的 Worker，並由使用者主動勾選個資確認後傳送。

## 個資安全
未匿名的姓名、電話、地址、身分證字號、病歷／診斷、家暴、兒少與其他可識別資訊，不得直接送往外部 AI。系統提供 OCR 文字區自動遮蔽與手動遮蔽框，但使用者仍須自行確認匿名化是否充分，並遵循機構規範。
