# 家系圖快速製作器 V6.1.2

## 一般使用者
1. 匯入手繪／掃描圖。
2. 執行本機智慧掃描。
3. 開啟「AI 協助判讀」。
4. 檢查並補上個資遮蔽。
5. 完成兩項確認後，按「開始 AI 判讀」。

一般使用者不需要輸入 Cloudflare Worker 網址。

## 管理者第一次設定
1. 進入 `cloudflare-worker`，執行對應作業系統的部署檔。
2. 複製部署完成後的 `https://...workers.dev`。
3. 開啟 `AI服務設定精靈.html`，測試並下載 `ai-config.js`。
4. 把 `index.html` 與 `ai-config.js` 一起上傳 GitHub Pages。

## 個資安全
圖片傳送前必須遮蔽姓名、電話、地址、身分證字號、病歷、診斷、家暴、兒少及其他可識別資訊。家庭關係、年齡與服務單位組合也可能反向識別特定個案。AI結果只能作為草稿，必須人工核對。
