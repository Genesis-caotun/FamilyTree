# 家系圖快速製作器 V5.0.0

發布日期：2026-07-28

## 部署到 GitHub Pages

將 `index.html`、`styles.css`、`app.js` 三個檔案一起放在 `FamilyTree` 儲存庫根目錄：

```text
FamilyTree/
├─ index.html
├─ styles.css
└─ app.js
```

GitHub：Settings → Pages → Deploy from a branch → `main` / `/(root)`。

## V5 核心修正

- 長輩在上、晚輩在下。
- 同一世代所有成員固定在同一橫排。
- 夫妻／伴侶優先採男左女右。
- 同胞手足由左至右依長幼排列。
- 子女結構線從父母婚姻線中點向下，接共同手足線後再分支。
- 多次婚配仍維持同世代排列，第一任配偶距離核心人物最近。
- 收養／寄養使用虛線分支。

## 延續 V4 功能

- 非親子關係線自動避障與手動轉折。
- 容錯中文解析與未辨識回報。
- SVG／PNG 動態裁切。
- 一鍵匿名化。
- 手機／平板長按拖曳與微調。
- 離線使用，本機儲存。

## 個資提醒

JSON 專案會保留原始姓名與資料，即使畫布開啟匿名模式也一樣。請依單位規範妥善保存。
