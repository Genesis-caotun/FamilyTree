# 家系圖快速製作器 V6.0.0

## 使用方式

將 `index.html` 上傳至 GitHub Pages 儲存庫根目錄，或直接在電腦雙擊開啟，即可離線使用。

## V6 智慧掃描辨識

1. 匯入 JPG、PNG 或 WebP 手繪／掃描家系圖。
2. 按「智慧掃描辨識」。
3. 調整黑白門檻與最小符號尺寸後開始分析。
4. 在確認清單修改人物類型、姓名、年齡及關係。
5. 套用勾選結果，再於主畫布逐項確認。

智慧辨識預設完全在瀏覽器執行，不會自動上傳圖片。手寫文字辨識僅在瀏覽器支援 `TextDetector` 時嘗試執行；不支援時請在確認清單手動補正。

## 建議瀏覽器

Chrome 或 Edge 最新版本。Safari 可使用主要編輯功能，但本機文字偵測支援情況可能不同。
