# 家系圖快速製作器 V3

## GitHub Pages 部署
1. 將本資料夾內的 `index.html` 上傳到 FamilyTree 儲存庫根目錄。
2. 覆蓋舊版 `index.html` 並提交。
3. 等待 GitHub Actions 的 Pages 部署完成。

- 強化按鈕 Hover、Active、Focus 操作回饋
